## GMTK Game Jam 2026 : Keep the world ticking !

Never has so much power been held by so few. The President of the USA (Unilateral Sanctions Authority), YOU, has access to a state-of-the-art computer to access everything the country has to offer... Including the nuclear codes.

After unintentionally hitting the nuclear button, the countdowns to Armageddon will appear, each linked to a country. Will you let them hit 0 or try to desperately juggle between every one to keep everyone alive ?

 If even one countdown reaches 0, you lose !

Good luck Mr. Président.

Controls : 

    The mouse (left click) 
    Arrow key or WASD (minigame with arrows) 

Hi !

We are a French team of friends, this is our first game and our first game jam ! 

We made a game where you have to solve different minigames to keep the countdowns from reaching 0. For example, clicking a button, answering a math question or resolving captchas ! The tasks should be self explanatory. We had a lot of fun making it !

After a lot of brainstorming, we found that it would be a fun idea to try to manage multiple countdowns in panic mode ! We then tried to make it fun with the story and graphics.

All of the art was done by Maxime and Romain, using Aseprite, while Robin and Raphaël made the game using Godot. Music was made by Émile.
